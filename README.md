# M & E Advocates ⚖️

A fully responsive multi-page website for M & E Advocates,
a premier law firm based in Nairobi, Kenya offering expert
legal services across multiple practice areas.

---

## 🌐 Live Site
[View Live Site](https://christianomungala-arch.github.io/mande-law)

---

## 📄 Pages

| Page | File | Description |
|------|------|-------------|
| Home | `index.html` | Hero, services overview, why choose us |
| About | `about.html` | Firm history, values and team |
| Services | `services.html` | Practice areas with JS filter |
| Attorneys | `attorneys.html` | Lawyer profiles and specializations |
| Blog | `blog.html` | Legal news and articles |
| FAQ | `faq.html` | Common legal questions with live search |
| Testimonials | `testimonials.html` | Client reviews and success stories |
| Contact | `contact.html` | Contact form with JS validation |

---

## 🛠️ Technologies Used

- **HTML5** — Semantic page structure
- **CSS3** — Custom styles, transitions, dark mode
- **JavaScript (ES6+)** — Dark mode, form validation, filters
- **Bootstrap 5** — Responsive grid, navbar, accordion
- **Bootstrap Icons** — Icons throughout the site
- **Git & GitHub** — Version control with incremental commits

---

## ✨ Features

- ✅ Fully responsive on desktop, tablet, and mobile
- ✅ Consistent navy and gold design across all 8 pages
- ✅ Dark/Light mode toggle saved in localStorage
- ✅ Contact form with JavaScript validation
- ✅ Filterable practice areas by category
- ✅ FAQ live search functionality
- ✅ Bootstrap accordion for FAQ
- ✅ Back to top button on all pages
